# Google Form Checkpoint Extension

This enables a `checkpoint` shortcode for adding in a Google Form to a page.

## Using

Grab the ID of the longform URL of the Google Form e.g.
`https://docs.google.com/forms/d/e/1FAIpQLSeIjgiBz_nh0d4dN9nLuU7sUkVTF-gdmqFlrEuSqTfJiwikXg/viewform`
and the ID is `1FAIpQLSeIjgiBz_nh0d4dN9nLuU7sUkVTF-gdmqFlrEuSqTfJiwikXg`

Then type in the following shortcode into your document such as the example.

## Example

`{{< checkpoint  id="1FAIpQLSeIjgiBz_nh0d4dN9nLuU7sUkVTF-gdmqFlrEuSqTfJiwikXg" >}}`
